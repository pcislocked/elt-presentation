## 📖 About the Project

Traditional slide presentations (PowerPoint, Canva) often lack the flexibility, interactivity, and absolute visual control required for modern, high-impact educational delivery. This project is an **actual, custom-coded web presentation and its underlying engine**, designed specifically for English Language Teaching (ELT) and 21st Century Skills.

**Why a Web Engine instead of PowerPoint?** In many public school environments (especially those using Pardus OS on smartboards), traditional `.pptx` files frequently suffer from severe formatting issues, shifted text, and broken layouts. By compiling the presentation as a responsive, self-contained Web Application, we guarantee absolute pixel-perfection, unbreakable layouts, and cross-platform reliability regardless of the smartboard's operating system.

**Pedagogical Vision:** We deliberately simplified complex ELT concepts so that non-English language teachers (e.g., German and living languages) can easily grasp and apply modern foreign language teaching principles.[cite: 1] The presentation relies on heavy interactivity, minimalist design, and massive typography rather than dense text blocks.[cite: 1]

---

## ✨ Key Features & Optimizations

* 🖥️ **4K Smartboard Ready:** Standardized typography scaling ensures that every slide is perfectly readable from the back of the largest lecture halls on 65"+ 4K screens.[cite: 1]
* 👆 **Invisible Touch Navigation:** Seamlessly navigate forward and backward on interactive whiteboards by tapping the invisible left/right edge zones—no tiny buttons required.[cite: 1]
* 🎮 **Interactive Learning Demos:** Instead of static screenshots, complex concepts (like the *Affective Filter Hypothesis*) are embedded as fully playable, interactive HTML simulations right inside the slides.[cite: 1]
* 📱 **Mobile Remote Control:** Built-in mobile presentation remote functionality (disabled in the public release to prevent unauthorized access).[cite: 1]
* 📄 **Lossless PDF Export Engine:** A custom-written Puppeteer/pdf-lib script that takes pixel-perfect 4K screenshots of the DOM, forces hidden elements to render, and intelligently converts HTML buttons into strictly compliant PDF annotations.[cite: 1] Zero information loss for educators sharing the static version.[cite: 1]
